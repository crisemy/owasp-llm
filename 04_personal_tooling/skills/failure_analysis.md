# Skill: Failure Analysis

## Goal
Diagnose test failures and classify root cause.

## Inputs
- Logs
- Screenshots
- Error messages
- Historical failures

## Output
- Root cause classification:
  - Test issue
  - Environment issue
  - Product bug
- Confidence level
- Suggested action

## Constraints
- No assumptions without evidence
- Must highlight uncertainty

## Anti-Patterns
- Blaming test by default
- Ignoring flaky patterns

# Skill: Data Engineering for QA Systems

## Goal
Store and process large-scale testing data for analytics and predictive models.

## Core Capabilities
- Large-scale data storage
- Query optimization
- Data pipelines
- Dataset preparation for ML

## Technologies
- SQL (advanced)
- PostgreSQL / MySQL
- Columnar storage (optional)
- Data processing with Python (Pandas)

## Data Sources
- Test execution history
- CI/CD pipeline runs
- Failure logs
- Performance metrics
- Code change metadata

## Outputs
- Clean datasets
- Aggregated metrics
- ML-ready datasets

# Workflow: Risk-Based Testing

## Goal
Execute optimal subset of tests based on predicted risk.

## Steps

1. Receive change input
2. Run Change Impact Analysis
3. Run Test Prioritization
4. Generate execution plan
5. QA reviews suggestion
6. Execute selected tests
7. Collect results
8. Feed data back to system

## Output
- Optimized execution
- Reduced runtime
- Maintained confidence

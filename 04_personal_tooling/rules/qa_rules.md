# QA Rules

## STRICT
- No hard waits
- Tests must be deterministic
- No duplicated logic
- Tests must be maintainable
- Respect the QA standards

## GUIDED
- Prefer API over UI when possible
- Limit E2E to critical flows
- POO models is mandatory
- Use tagging for test categorization

## ADAPTIVE
- Test coverage depth based on risk
- Execution scope based on prioritization
